## Compilation

To compile this CV, you will need to have Git and Docker installed, then:
``` bash
git clone git@github.com:fbertet/curriculum-vitae.git
cd curriculum-vitae
make
```

Wait ~30 seconds and look at the resulting .pdf files in the `outputs/` directory.
